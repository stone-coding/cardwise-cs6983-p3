# CLAUDE.md setup guide

Do not treat this as an already completed HW4 artifact. Run Claude Code `/init` for real, preserve output, and refine its generated CLAUDE.md based on the actual repository.

Recommended topics: project mission and frozen scope; stack and commands; architecture; roles and data safety; code style; TDD and Git workflow; no-secret policy; reward calculation assumptions; test coverage; explicit `@docs/MVP_SCOPE.md` or similar @import syntax as supported by installed Claude Code version.

Claude Code permissions/hooks/MCP syntax can change. Validate against your installed CLI and official documentation; do not blindly paste unverified settings.
