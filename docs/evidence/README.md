# Evidence collection guide

Create `hw4/`, `hw5/`, and `p3/` subfolders as work progresses.
Capture real command output, timestamps, screenshots, git hashes, PR links, Claude Code session notes, CI results and deployment URLs. Do not place secrets or sensitive personal data in logs. Keep raw evidence and annotated explanations separate.

Suggested per-evidence note: date/time, task, command/workflow, observed result, commit/PR link, rubric item supported, limitations.
